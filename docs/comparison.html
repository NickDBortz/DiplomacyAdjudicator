✨ New Features

🛡️ Shield Army Symbol

A distinctive shield with a cross-sword in the center, representing land military forces with a clear military aesthetic.

⚓ Ship Fleet Symbol

A ship hull design with mast, sail, and anchor, representing naval forces with maritime symbolism.

🎨 Dynamic Coloring

Symbols automatically inherit player faction colors. Works with all 7 Diplomacy powers.

✨ Smart Highlighting

Blue glow for source units, gold glow for targets. Visual feedback for better UX.

🔍 Vector Scalability

SVG-based rendering scales perfectly at any zoom level without quality loss.

⚡ Optimized Performance

Efficient symbol reuse with SVG <use> elements. Minimal performance impact.
